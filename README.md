# valos-ideju-zajszintmero-es-hangelemzo
A projekt célja élő mikrofonjelek valós idejű zajszint- és frekvenciaelemzése. A sounddevice rögzíti a hangmintákat, amelyeken a numpy gyors Fourier-transzformációt (FFT) végez. A program kiszámítja a hangerőt (dB) és a domináns frekvenciát (Hz), riaszt határérték-túllépésnél, és élő grafikonon ábrázolja az adatokat.
